# Чек - лист

- Проект: Настольное приложение для замера потраченного времени на выбранную деятельность.
- Версия: 1.0
- Окружение: Windows 10 Version 22H2, PyCharm 2025.1.2, Python 3.12, CustomTkinter 5.2.2

## Работа с предметами

- ### Добавление предмета

- [ ] Добавить новый предмет
    - (ОР: Предмет добавлен в JSON, предмет появился в списке)
- [ ] Добавить дубликат предмета
    - (ОР: Появление сообщения синего цвета "Такой предмет уже есть")
- [ ] Добавить предмет с пустым названием
    - (ОР: Появление сообщения синего цвета "Введите имя предмета")
- [ ] Добавить предмет с названием длиной 26 символов
    - (ОР: Счётчик под полем ввода показывает 0, ввод остановится на 25 символах)

- ### Удаление предмета

- [ ] Удалить выбранный предмет
    - (ОР: Открывается окно с подтверждением об удалении)
- [ ] Удалить при пустом поле ввода
    - (ОР: Появление сообщения синего цвета "Выберите предмет для удаления")
- [ ] Удалить предмет при открытом окне секундомера этого предмета
    - (ОР: Открывается окно с подтверждением об удалении)
- [ ] Удалить предмет с запущенным секундомером этого предмета
    - (ОР: Появление окна предупреждения об активном секундомере и
      подтверждением об удалении. Секундомер остановился)
- [ ] Удалить предмет с остановленным секундомером этого предмета
    - (ОР: Появление окна предупреждения об активном секундомере и
      подтверждением об удалении.)

- ### Выбор предмета

- [ ] Нажать "Выбрать" с выбранным предметом из списка
    - (ОР: Открытие окна "Меню предмета")
- [ ] Нажать "Выбрать" при пустом поле ввода
    - (ОР: Появление сообщения синего цвета "Выберите предмет из списка или добавьте новый")

## Работа секундомера

- ### Запуск секундомера

- [ ] Нажать "Старт" зеленого цвета
    - (ОР: Значение времени начинает увеличиваться.
      Кнопка "Старт" сменилась на кнопки "Стоп" красного цвета и "Сброс" серого цвета)
- [ ] Нажать "Старт" после остановки секундомера
    - (ОР: Значение времени продолжило увеличиваться
      Кнопка "Старт" сменилась на красную кнопку "Стоп", кнопка "Сброс" осталась)

- ### Остановка секундомера

- [ ] Нажать "Стоп" красного цвета
    - (ОР: В окне показывает накопившееся время, не меняется.
      Кнопка "Стоп" сменилась на зеленую кнопку "Старт", кнопка "Сброс" осталась)

- ### Сброс

- [ ] Нажать "Сброс" при запущенном секундомере
    - (ОР: Время показывает "00:00:00".
      Кнопки "Сброс" и "Стоп" сменились на кнопку "Старт" зеленого цвета.
      Накопившееся время сохранилось в JSON, под датой старта секундомера)
- [ ] Нажать "Сброс" при остановленном секундомере
    - (ОР: Время показывает "00:00:00".
      Кнопки "Сброс" и "Стоп" сменились на кнопку "Старт" зеленого цвета.
      Накопившееся время сохранилось в JSON, под датой старта секундомера)
- [ ] Нажать "Сброс" сразу после запуска секундомера
    - (ОР: Накопившееся время сохранилось в JSON, под датой старта секундомера)

- ### Закрытие окна секундомера

- [ ] Нажать на крестик при запущенном секундомере
    - (ОР: Появление в центре окна приложения, окна предупреждения об активном секундомере и
      предложении сохранить результат. Секундомер остановился)
- [ ] Нажать на крестик при остановленном секундомере
    - (ОР: Появление в центре окна приложения, окна предупреждения об активном секундомере и
      предложении сохранить результат.)
- [ ] Нажать на крестик, значение "00:00:00"
    - (ОР: Окно секундомера закрылось)

## Отображение истории и статистики по предмету

- [ ] Создан новый предмет
    - (ОР: Отображается:
      Общее время: 00 ч. 00 м. 00 с.,
      Всего дней: 0,
      Средняя сессия: 00 ч. 00 м. 00 с.,
      Кнопка "Выбор периода" не активна.)
- [ ] Предмет с одной сессией 2 часа в один день
    - (ОР: Отображается:
      Общее время: 02 ч. 00 м. 00 с.,
      Всего дней: 1,
      Средняя сессия: 02 ч. 00 м. 00 с.,
      Кнопка "Выбор периода" активна.)
- [ ] Предмет с двумя сессиями по 1 часу в разные даты
    - (ОР: Отображается:
      Общее время: 02 ч. 00 м. 00 с.,
      Всего дней: 2,
      Средняя сессия: 01 ч. 00 м. 00 с.,
      Кнопка "Выбор периода" активна.)
- [ ] Предмет с тремя сессиями: 2 сессии по 1 часу, 1 сессия 2 часа. В разные даты
    - (ОР: Отображается:
      Общее время: 04 ч. 00 м. 00 с.,
      Всего дней: 2,
      Средняя сессия: 02 ч. 00 м. 00 с.,
      Кнопка "Выбор периода" активна.)
- [ ] Предмет с шестью сессиями по 10 секунд за одну дату
    - (ОР: Отображается:
      Общее время: 00 ч. 01 м. 00 с.,
      Всего дней: 1,
      Средняя сессия: 00 ч. 01 м. 00 с.,
      Кнопка "Выбор периода" активна.)
- [ ] Предмет с сессией меньше секунды
    - (ОР: Отображается:
      Общее время: 00 ч. 00 м. 00 с.,
      Всего дней: 1,
      Средняя сессия: 00 ч. 00 м. 00 с.,
      Кнопка "Выбор периода" активна.)

## Выбор периода

- [ ] Применить выбранный период
    - (ОР: Окно выбора периода закрылось,
      отображается статистика за выбранный период)
- [ ] Применить период только с датой начала
    - (ОР: Окно выбора периода закрылось,
      отображается статистика с начала периода до конца истории предмета)
- [ ] Применить период только с датой окончания
    - (ОР: Окно выбора периода закрылось,
      отображается статистика с начала истории до окончания периода)
- [ ] Нажать крестик окна "Выбор периода"
    - (ОР: Окно выбора периода закрылось,
      Статистика предмета осталась без изменений)
- [ ] Нажать "Применить" без выбора дат
    - (ОР: Окно выбора периода закрылось,
      Статистика предмета осталась без изменений)
- [ ] Применить одинаковые даты начала и окончания периода
    - (ОР: Окно выбора периода закрылось,
      отображается статистика за выбранную дату)

## Корректная работа пользовательского интерфейса (UI)

- [ ] Запустить приложение
    - (ОР: Окно приложения открывается в центре экрана)
- [ ] Проверка отображения текста в интерфейсе
    - (ОР: Текст не обрезается и отображается корректно)
- [ ] Нажать "Добавить новый"
    - (ОР: Окно "Новый предмет" всегда открывается в центре окна приложения)
- [ ] Нажать "Удалить предмет"
