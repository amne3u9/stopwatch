# BR_003

## Заголовок

Сессия пересекающая полночь, сохраняется с датой сброса.

## Описание

Если запустить секундомер до полуночи (например, в 23:58) и завершить сессию после полуночи (00:02), 
сессия сохраняется с датой завершения, а не с датой начала.
Такая логика сохранения сессий отразится на некорректном подсчете статистики.

## Окружение

Версия приложения: 1.0  
OS: Windows 10 22H2  
IDE: PyCharm 2025.1.2  
Python: 3.12  
Framework: CustomTkinter 5.2.2

## Шаги воспроизведения

1. Выбрать предмет из выпадающего списка
2. Нажать кнопку "Выбрать"
3. Нажать кнопку "Секундомер"
4. В 23:58 в окне секундомера нажать кнопку "Старт"
5. В 00:02 в окне секундомера нажать кнопку "Сброс"

## Фактический результат

В файле demo_data.json сессия добавлена на дату сброса секундомера

## Ожидаемый результат

В файле demo_data.json сессия должна быть добавлена на дату старта секундомера
