# BR_001

## Заголовок

Удаление предмета с запущенным секундомером происходит без предупреждающего сообщения.

## Описание

Если удалить предмет, у которого запущен секундомер,  
приложение не показывает предупреждение об активном секундомере и не останавливает его.
Удаление предмета при активном секундомере может привести к ошибке при сохранении сессии (KeyError),  
так как объект предмета больше не существует.

## Окружение

Версия приложения: 1.0  
OS: Windows 10 22H2  
IDE: PyCharm 2025.1.2  
Python: 3.12  
Framework: CustomTkinter 5.2.2

## Шаги воспроизведения

1. Выбрать предмет из выпадающего списка
2. Нажать кнопку "Выбрать"
3. Нажать кнопку "Секундомер"
4. В окне секундомера нажать кнопку "Старт"
5. В окне приложения нажать кнопку "Назад" (стрелка в верхнем левом углу)
6. Нажать кнопку "Удалить предмет"

## Фактический результат

Открывается окно "Удаление предмета" с подтверждением удаления.
Предупреждение об активном секундомере не появляется.
Секундомер продолжает работать.

## Ожидаемый результат

Перед удалением предмета появляется окно предупреждения: 
"У этого предмета есть активный секундомер. Удалить предмет?"
Секундомер должен остановиться.
