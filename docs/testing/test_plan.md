# Введение и цель

Данный документ описывает план тестирования настольного приложения для замера потраченного времени на выбранную
деятельность.
Цель тестирования — снижение рисков выпуска неработающего приложения и проверка соответствия установленным требованиям.

# Область тестирования

В рамках тестирования будут проверены следующие функции:

- Работа с предметами: добавление, удаление, выбор предмета
- Работа секундомера: запуск, остановка, сброс секундомера
- Отображение истории и статистики по предмету
- Выбор периода: фильтрация истории и статистики за выбранный период
- Работа с JSON: сохранение и загрузка данных из JSON файла
- Поведение приложения при закрытии: предупреждение о не сохраненной сессии
- Корректная работа пользовательского интерфейса (UI): отображений окон, кнопок, текста

В рамках тестирования не будут проверены функции:

- Импорт данных из JSON файла
- Корректность отображения цветовых схем (Dark / Light mode) при смене системной темы
- Работа приложения на операционных системах, отличных от Windows

# Виды тестирования

Будут использованы следующие виды тестирования:

- Ручное тестирование
- Функциональное тестирование
- Тестирование пользовательского интерфейса (GUI)
- Тестирование граничных значений (edge cases)
- Негативное тестирование

# Тестовое окружение

- OS: Windows 10
- Python: 3.12
- GUI Framework: CustomTkinter

# Критерии завершения

Тестирование будет считаться завершенным при выполнении следующих условий:

- Все запланированные тестовые сценарии выполнены
- Отсутствие дефектов со статусом Critical / High
- Все обнаруженные дефекты задокументированы
